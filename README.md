# 🐘 Estudos de PHP

Repositório dedicado aos meus estudos de **PHP e Desenvolvimento Web**.

Aqui registro exercícios, experimentos e projetos desenvolvidos durante minha jornada de aprendizado, buscando não apenas aprender a linguagem PHP, mas principalmente **entender como a Web realmente funciona por trás das aplicações que utilizamos no dia a dia**.

##  Objetivo

Minha principal meta é **desenvolver meus conhecimentos em Desenvolvimento Web e entender como a Web realmente funciona**.

O estudo do PHP será utilizado como uma forma de compreender, na prática, conceitos fundamentais do desenvolvimento web, como:

- Como um navegador se comunica com um servidor;
- O que são requisições e respostas HTTP;
- Como o servidor processa uma requisição;
- Como o PHP é executado no lado do servidor;
- Como dados são enviados entre Front-End e Back-End;
- Como formulários funcionam;
- Como aplicações armazenam e recuperam dados;
- Como o Back-End se comunica com bancos de dados;
- Como autenticação e sessões funcionam;
- Como APIs permitem a comunicação entre sistemas;
- Como aplicações Web são estruturadas.

A ideia não é apenas **aprender a escrever código**, mas compreender o que acontece por trás dele.
