# 📦 Sistema de Cadastro de Produtos

## 📌 Sobre o projeto

Este projeto consiste em um sistema web para cadastro e gerenciamento de produtos, desenvolvido com o objetivo de praticar conceitos fundamentais do desenvolvimento backend com PHP e integração com banco de dados MySQL.

O projeto faz parte da minha evolução prática como desenvolvedor, aplicando conceitos de programação, manipulação de dados e desenvolvimento de interfaces web.

## 🛠️    Tecnologias utilizadas

- **PHP** — lógica e processamento backend.
- **MySQL** — armazenamento e gerenciamento dos dados.
- **PDO** — conexão com o banco de dados e execução de consultas.
- **HTML5** — estrutura das páginas.
- **CSS3** — estilização da interface.
- **Bootstrap 5.3.8** — construção de uma interface responsiva.

## ⚙️ Funcionalidades

- Cadastro de produtos.
- Armazenamento de informações no banco de dados.
- Organização dos produtos por categoria.
- Registro de nome, preço, quantidade e categoria.
- Listagem dos produtos cadastrados.

## 🗄️ Estrutura dos dados

A tabela `produtos` utiliza os seguintes campos:

| Campo | Descrição |
|---|---|
| `id` | Identificador do produto |
| `nome` | Nome do produto |
| `preco` | Preço do produto |
| `quantidade` | Quantidade em estoque |
| `categoria` | Categoria do produto |
| `criado_em` | Data e hora do cadastro |

## 💻 Como executar o projeto

### 1. Pré-requisitos

- XAMPP instalado.
- PHP e MySQL disponíveis.
- Navegador web.

### 2. Clonar o repositório

```bash
git clone URL_DO_SEU_REPOSITORIO
```

### 3. Configurar o projeto

Coloque a pasta do projeto no diretório `htdocs` do XAMPP.

Configure as credenciais de conexão com o MySQL no arquivo de conexão do projeto.

### 4. Configurar o banco de dados

Crie o banco de dados no phpMyAdmin e configure a tabela `produtos` conforme a estrutura utilizada pelo sistema.

### 5. Executar

Inicie o Apache e o MySQL no XAMPP e acesse o endereço local do projeto pelo navegador.
