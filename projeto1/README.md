#  Sistema de Assistência Técnica

Sistema web desenvolvido para uma empresa de assistência técnica de informática, criado com o objetivo de substituir o controle manual de clientes, equipamentos, técnicos e serviços de manutenção por uma solução centralizada e organizada.

##  Contexto

O projeto foi desenvolvido a partir de um cenário em que o controle das informações de uma assistência técnica era realizado de forma manual e descentralizada.

Dados de clientes, equipamentos recebidos e serviços realizados podiam ficar espalhados em diferentes registros, tornando o acompanhamento dos atendimentos mais trabalhoso e aumentando a possibilidade de erros, perda de informações e retrabalho.

A partir desse problema, surgiu a necessidade de desenvolver uma aplicação capaz de centralizar essas informações e facilitar o gerenciamento dos atendimentos.

---

##  O problema

O controle manual apresentava algumas dificuldades para a rotina da empresa:

- Dificuldade para localizar informações dos clientes;
- Falta de organização dos equipamentos recebidos;
- Dificuldade para acompanhar o andamento dos serviços;
- Falta de centralização das informações;
- Possibilidade de perda ou preenchimento incorreto de dados;
- Dificuldade para consultar informações de atendimentos;
- Falta de controle sobre quem poderia acessar determinadas informações.

Além disso, conforme a quantidade de clientes e serviços aumenta, manter essas informações manualmente se torna cada vez mais difícil de administrar.

---

##  A solução

Para solucionar esse problema, foi desenvolvido um sistema web capaz de centralizar as principais informações da assistência técnica em um único ambiente.

A aplicação permite que os usuários autenticados possam:

- Cadastrar e gerenciar clientes;
- Cadastrar e gerenciar equipamentos;
- Cadastrar e gerenciar técnicos;
- Criar e acompanhar ordens de serviço;
- Relacionar equipamentos aos seus respectivos clientes;
- Relacionar ordens de serviço aos clientes, equipamentos e técnicos;
- Atualizar informações dos atendimentos;
- Controlar o acesso ao sistema através de autenticação e perfis de usuário.

Dessa forma, o sistema transforma um processo anteriormente descentralizado em um fluxo digital organizado.

---

##  Tecnologias utilizadas

O sistema foi desenvolvido utilizando tecnologias voltadas para o desenvolvimento web, estilização de interfaces e gerenciamento de dados.

- **PHP:** responsável pela lógica do sistema, processamento de formulários, autenticação e comunicação com o banco de dados.
- **MySQL:** utilizado para armazenar e organizar os dados de clientes, equipamentos, técnicos, usuários e ordens de serviço.
- **HTML5:** utilizado para estruturar as páginas da aplicação.
- **CSS3:** utilizado para personalizar a aparência e o layout do sistema.
- **Bootstrap:** utilizado para auxiliar na construção e estilização da interface, contribuindo para uma apresentação mais organizada e responsiva.
- **XAMPP:** utilizado como ambiente de desenvolvimento local, disponibilizando o servidor Apache e o banco de dados MySQL.

---

## 🛠️ Ferramentas de desenvolvimento

- **Git:** utilizado para o versionamento do código-fonte.
- **GitHub:** utilizado para hospedar o repositório e acompanhar a evolução do projeto.
- **GitHub Copilot:** utilizado como ferramenta de apoio na criação e estilização do CSS, ajudando a agilizar o desenvolvimento da interface e otimizar o tempo de implementação.

O Copilot foi utilizado como apoio ao desenvolvimento, enquanto a implementação das funcionalidades e a organização do sistema faziam parte do processo de construção da aplicação.

---

##  Aprendizados

O desenvolvimento deste projeto proporcionou a oportunidade de colocar em prática os conhecimentos adquiridos em programação PHP e banco de dados, aplicando-os na construção de uma aplicação web.

Durante o desenvolvimento, foram trabalhados conceitos como:

- Operações de cadastro, consulta, atualização e exclusão de registros (CRUD);
- Modelagem e relacionamento entre tabelas no MySQL;
- Integração entre PHP e banco de dados;
- Processamento e validação de formulários;
- Autenticação e gerenciamento de sessões;
- Controle de acesso por perfis de usuário;
- Organização do código e versionamento com Git e GitHub;
- Utilização de ferramentas de inteligência artificial como apoio ao desenvolvimento.

Além disso, o projeto contribuiu para compreender melhor como diferentes tecnologias trabalham juntas na construção de um sistema web e como os conhecimentos teóricos podem ser aplicados para resolver problemas práticos.
